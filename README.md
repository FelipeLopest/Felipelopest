Programo há 3 anos e atualmente estudo Desenvolvimento de Sistemas na ETEC. Trabalho com o ciclo completo de uma aplicação — modelagem de dados, API, regras de negócio e interface — e gosto de projetos onde consigo acompanhar a coisa do início ao fim.
